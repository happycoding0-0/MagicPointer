# 🪄 Magic Pointer (독립형 인터랙션 코어 엔진)

> **본 프로젝트는 다른 소프트웨어 아키텍처에 라이브러리처럼 플러그인하여 재사용할 수 있도록, UI(시각적 표시)와 UX(의도 감지) 레이어를 완벽하게 분리한 독립형 인터랙션 프레임워크(졸업작품)입니다.**

## ⏳ Project History & Timeline (원천 아이디어 증명)
본 엔진의 핵심 사상은 구글 딥마인드(Google DeepMind, 2026.05)의 발표 이전에 독자적으로 고안되었습니다.

- **2025.12 :** 1세대 드래그 기반 직관적 학습 툴 `Lose My Mind` 개발 (흐름 단절 문제 최초 해결) -> "직관적 인터랙션 직접 고안했다"라는 강조 및 인터랙션의 논리적 정의와 설명이 존재하지않음
- **2026.05 :** Google DeepMind의 'Mouse Pointer 재정의' 리포트 발표로 동일한 철학적 비전 확인
- **현재 (2026) :** 과거 기능 중심 코딩의 한계를 극복하고, UI/UX 레이어를 분리하여 '라이브러리화'가 가능하도록 독립형 인터랙션 엔진 아키텍처로 고도화 (졸업작품)

## 🏗️ Architecture: 관심사의 분리 (SoC)
- **UI/UX 레이어 (가변) :** 특정 키 입력 조건 감지 및 안내 박스 실시간 렌더링 (커스텀 및 업그레이드 가능)
- **코어 로직 레이어 (고정) :** HTML DOM 구조 분석 및 문자열 채굴 (`caretRangeFromPoint`) -> 라이브러리 형태로 어떤 프로젝트든 즉시 가져다 재사용 가능
