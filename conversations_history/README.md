## 🔄 다른 PC에서 대화 내역 동기화하는 방법

Antigravity는 클라우드 자동 동기화 기능이 제공되지 않으므로, 다른 PC(예: 사무실 PC)의 대화를 이 노트북으로 가져오려면 다음 폴더들을 직접 복사하여 붙여넣어야 합니다.

### 1. 복사해야 할 폴더 경로 (이전 PC)

- 대화 내용 로그 및 아티팩트: `C:\Users\<이전PC_사용자명>\.gemini\antigravity\brain\` 하위의 대화 ID 폴더들

- 대화 세션 상태 파일: `C:\Users\<이전PC_사용자명>\.gemini\antigravity\conversations\` 하위의 파일들 (대화ID.db, 대화ID.pb 등)

### 2. 붙여넣을 폴더 경로 (현재 노트북)

- 대화 내용 로그: `C:\Users\skyje\.gemini\antigravity\brain\` 폴더 안에 복사한 폴더들을 붙여넣습니다.

- 대화 세션 파일: `C:\Users\skyje\.gemini\antigravity\conversations\` 폴더 안에 복사한 파일들을 붙여넣습니다.

### 3. 붙여넣은 후 대화 기록 내보내기 다시 실행

파일을 붙여넣은 후 이 스크립트(`export_transcripts.py`)를 다시 실행하면, 새로 추가된 대화 내역들도 이곳 `conversations_history/` 디렉터리에 자동으로 마크다운 문서로 변환되어 인덱스(`README.md`)에 등록됩니다. 이를 통해 VS Code 등 에디터에서 편리하게 이전 대화 내용을 확인하실 수 있습니다.
